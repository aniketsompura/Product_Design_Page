# Principle

A numbered statement set huge in Funnel Display, with a handwritten note under it in `accent`.

**Use it** for principles, values and the one big claim of a page. On the story page the words fill in from 18% to full opacity as you scroll; elsewhere show them at full strength.

**Markup:** `<ol class="cv-principles">` of `<li class="cv-principle">` with `<p class="cv-principle__text">` and `<p class="cv-principle__note">`. The two-digit number comes from a CSS counter in `accent`.

- Do: write each statement as an imperative under eight words (“AI drafts. Designers decide.”).
- Do: keep the note lowercase and short (“fast, never on autopilot”).
- Don't: use more than five on a page.
