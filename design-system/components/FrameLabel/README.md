# FrameLabel

The small “# Name” label that sits above every frame and section, exactly as a design tool labels a frame on its canvas.

**Use it** above a page section, a card group, a story stage or any frame you want people to read as one object. It names the thing below it.

**Markup:** `<p class="cv-frame-label">What we do</p>`. The `#` is added by CSS in `accent`; the label text is `frame-label` (Geist Mono 13px) in `ink-2`.

- Do: keep it to two to four words in sentence case, naming the content (“Team”, “Tools we built”, “Enrollment health”).
- Do: put it 8 to 12px above the frame's top edge, aligned to the frame's left edge.
- Don't: use it as a heading. The heading still comes after it; the label is an aside for people who scan.
- Don't: stack two labels or add icons to it.
